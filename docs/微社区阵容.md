# 微社区阵容与来源开关

微社区是金铲铲官方攻略的一个渠道，和官网推荐共用官方基础资料。此前后台已抓取并存储微社区，但界面只提供官方/dataj 两个开关；阵容库又读取了推荐引擎的关联去重集合。草龟沙皇攻略已存在，却因关联到 dataj「赌沙皇」而在“全部”里隐藏。原始详情读取还会沿关联跳到统计阵容，导致标题与攻略不对应。

现在阵容库保留每条原始记录，推荐继续保留原有关联去重策略。草龟沙皇可在“全部”或“微社区”按原名检索，打开的是原始攻略、英雄、站位和装备。原始 ID 保持 `official:<攻略 ID>`，无需数据库迁移。

## 界面操作

1. 打开顶部赛季菜单，分别控制「官网推荐」「微社区」「dataj.cc（阵容统计）」；也可以在「设置 → 数据」修改并保存。
2. 进入「阵容库」，选择全部、官网推荐、微社区或 dataj 胜率；搜索框匹配原始标题与核心英雄。
3. 选择一行后查看右侧原始详情；较窄桌面会弹出检查器，可用右上角关闭按钮返回列表。
4. 本局锁定、默认锁定和关注保留用户点选的原始记录状态。推荐计算仍可解析为已关联的统计阵容，展示原始详情不会改变引擎算法。
5. 关闭渠道立即刷新浏览与推荐，清除失去可用渠道的锁定和关注。双渠道攻略有任一渠道开启便继续可用。三项全关会显示无推荐状态，点击同步明确提示至少开启一个来源。

官网与微社区的归属来自攻略的渠道信息。同一 ID 同时属于两个渠道，在“全部”里只算一条；库内数量是存储数量，当前列表仍受来源开关与搜索限制。不能把官网数与微社区数直接相加当成唯一总数。数据库统计同时区分原始目录总数和关联去重后的推荐数。

微社区目前仅支持自然之力 `18_S19`。其他赛季的微社区筛选为空，并显示当前赛季不支持；不会扩大到未经验证的赛季地址。

## 同步与统计口径

官网或微社区任一开启，都会同步一次完整官方快照：英雄、羁绊、装备、海克斯、赛季机制，以及官网和微社区两个攻略渠道。这能保留完整原始存档和关联信息，避免只抓半个渠道后覆盖另一渠道的历史记录。来源开关决定哪些攻略参与浏览和推荐。只开微社区也能从空库建立官方基础资料；官网与微社区均关闭时不建立官方同步客户端。

dataj 提供胜率、均名、出场率和阵容统计；开启它时补齐统计数据，基础资料仍优先官方。微社区的使用、周使用、收藏和评论是热度，详情单独注明统计日期与“非胜率”；缺失值保持未知，不换算或推断胜率。

「同步最新数据」会主动抓取当前赛季。打开界面时的自动同步主要按“未同步过/官方版本变化”判断；微社区可能在游戏版本不变时新增攻略，这时请手动同步。`jcc db check` 可主动查询版本，但不会因此下载全部英雄与攻略。

## 命令行

```bash
jcc db sync --sources official,ingame,dataj
jcc db sync --sources ingame
jcc comps --source ingame --top 100
jcc comps --source official --top 100
jcc comps --top 10
```

`official` 指官网推荐，`ingame` 指微社区，`dataj` 指统计来源。`--sources` 指定本次同步来源，显式覆盖全部三项，不留下默认开启的微社区，也不保存修改到设置；未知或空来源会被拒绝。官网/微社区任一项仍触发共享完整官方同步。`comps --source` 遵循已保存的来源开关；`all` 默认保持推荐排行与关联去重，单渠道列出该渠道可用的原始攻略。

## 隔离启动与验收

可用独立数据目录启动，避免覆盖自己的设置：

```bash
cd web && npm ci && npm run build
cd ..
PYTHONPATH=src JCC_HOME="$PWD/var/community-manual" .venv/bin/python -m jccbrain gui
```

`var/community-manual` 应取全新目录。
