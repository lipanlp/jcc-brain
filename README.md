# 金铲铲大脑

金铲铲之战（PlayCover 运行的 iOS 版）的 macOS 本地 AI 分析决策工具：实时读取对局画面，结合
[金铲铲官方资料库](https://jcc.qq.com/)（权威数据）与 [dataj.cc](https://www.dataj.cc/comp) 阵容统计给出决策，也可以半自动 / 全自动地替你操作。

- **辅助大脑**：只看不动，实时给出本回合最佳建议（运营、买卖、目标阵容、海克斯、装备）。
- **自动 D 牌**：按目标卡自动刷新、买卡，实时计算牌库剩余与命中率，到保留金币线或凑齐即停。
- **全自动托管**：从开局到结束由 AI 决策并执行。
- **HUD 浮层**：棋子头顶显示名字 / 星级 / 羁绊，商店高亮建议购买，海克斯选项显示评分；另有可拖动的目标卡概率面板。
- **数据库**：按官方赛季分别存储（自然之力、英雄联盟传奇、英雄联盟传奇·恭喜发财、画之灵、时空裂痕，列表随官网刷新）。
  阵容来源可独立选择**官网推荐、微社区、dataj 统计**。官网或微社区任一开启，基础数据以官方为准：英雄、羁绊、装备、海克斯、自然仙灵、开局奇遇和阵容攻略；
  dataj.cc 补阵容胜率统计、阵容内海克斯表现、过渡站位（只有自然之力、英雄联盟传奇有）。
  微社区目前支持自然之力；同一攻略跨官网/微社区只出现一次。阵容库保留原始标题与详情，推荐另按关联去重，微社区热度不代表胜率。详见 [微社区阵容说明](docs/微社区阵容.md)。

架构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，开发规范见 [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)。

## 安装

```bash
brew install uv
brew install node # 前端构建需要 Node.js 和 npm
make setup        # 建 .venv（Python 3.12）并安装依赖
make sync         # 按设置来源同步游戏资料和阵容
make gui          # 打开界面
```

打包成独立应用：`make app` → `dist/金铲铲大脑.app`（可拷到「应用程序」直接双击运行）。
打包版自带前端资源和运行环境，无需另装 Node.js；运行数据在 `~/Library/Application Support/金铲铲大脑/`。
开发时使用仓库内 `var/`，两种运行方式都可通过 `JCC_HOME` 指定其他数据目录。

### 权限

| 权限 | 谁需要 | 用途 |
|---|---|---|
| 录屏 | 运行 jcc 的终端 / 金铲铲大脑.app | 读取游戏画面 |
| 辅助功能 | 运行 jcc 的终端 / 金铲铲大脑.app | 自动操作发送鼠标事件 |

在「系统设置 → 隐私与安全性」里授权。工具栏右侧扳手菜单中的「检查视觉模块 / 检查操作权限」可以自查。

## 图形界面

`make gui` 先构建 Vue 3 前端，再打开 pywebview 窗口；`jcc gui` 或不带参数的 `jcc` 打开同一个界面。

启动读取数据时，工作区会显示准备提示，仍可切换页面或打开设置。读取失败会自动尝试最多三次，之后可用“重试”重新读取；成功后提示消失。若窗口看起来正常但侧栏点击没有反应，请保留 `var/logs/jcc.log`，也可用 `jcc -v gui` 记录详细启动日志。准备提示与重试用于恢复数据读取，不代表所有原生窗口点击问题已定位。

左侧栏包含五个页面：

- **实时决策**：对局指标、运营与买卖建议、目标卡概率、棋子羁绊和装备随画面更新。
- **牌库概率**：添加目标英雄，计算刷新概率并模拟 D 牌，可跟随实时等级和金币。
- **阵容库**：筛选官网推荐、微社区和 dataj 统计，按原始阵容名或核心英雄搜索，在右侧检查器浏览站位、装备、海克斯与原始攻略，锁定或关注阵容。
- **数据库**：检索英雄、羁绊、装备、海克斯、赛季机制、开局奇遇和官方攻略，并查看完整详情。
- **日志**：按来源、级别和文字筛选运行记录，支持自动滚动、复制和清空。

顶部工具栏可以启动辅助大脑、自动 D 牌或全自动托管，并随时停止。HUD 按钮开启透明、鼠标穿透的游戏浮层，
概率面板按钮开启可拖动的置顶小窗口。赛季弹出框提供赛季切换、数据源、同步和数据库统计；AI 弹出框提供开关、
档位和测试连接。右侧扳手菜单提供标注单位、坐标标定、检查视觉/操作权限、打开回放和关于。

赛季弹出框和「设置 → 数据」均可控制三项来源，保存后立即影响浏览、推荐与阵容选择。关闭来源会清理该来源的锁定/关注；三项全关可保留为空，手动同步时会要求至少开启一项。官网与微社区共用完整官方资料同步，开任一项都会存下两个渠道，浏览仍遵守各自开关。自动同步主要检查版本变化；同版本下新发的微社区攻略请手动点击「同步最新数据」。

底部状态栏显示运行模式、同步进度、赛季、AI、操作和视觉信息。点击「演练 / ⚠️ 真实」可切换操作方式，
关闭演练会要求确认。左下角「设置」或 `⌘,` 打开设置面板，包含视觉、数据、大模型、操作、自动 D 牌、HUD 和外观；
外观支持跟随系统、浅色和深色。

| 快捷键 | 功能 |
|---|---|
| `⌘1` / `⌘2` / `⌘3` | 启动辅助大脑 / 自动 D 牌 / 全自动托管 |
| `⌘.` | 停止当前模式 |
| `⌘H` | 开关 HUD 浮层 |
| `⌘J` | 开关概率小面板 |
| `⌘,` | 打开设置 |
| `⌘L` | 标注单位 |
| `⌥⌘1`～`⌥⌘5` | 按侧栏顺序切换五个页面 |
| `⌘⇧1` / `⌘⇧2` / `⌘⇧3` | 切换极速 / 均衡 / 深度 AI 档位 |

## 命令行

```bash
jcc db sync                      # 按设置同步当前赛季，--quick 跳过 dataj 逐阵容详情
jcc db sync --sources official,ingame,dataj  # 本次显式覆盖全部三项来源，不保存为设置
jcc db sync --sources ingame      # 只消费微社区；仍同步完整官方基础资料和两个攻略渠道
jcc db season                    # 列出官方赛季与同步情况；jcc db season 自然之力（或 18_S19）切换当前赛季
jcc comps --top 10               # 阵容排行
jcc comps --source ingame --top 100  # 微社区原始攻略（遵循来源设置）；all 默认排行保持关联去重
jcc hero 绯红树怪                 # 英雄、羁绊、所在阵容
jcc odds 厄斐琉斯 --level 8 --need 2            # 刷新概率
jcc rolldown 厄斐琉斯=2 婕拉=2 --gold 60 --level 8   # D 牌模拟
jcc advise                       # 辅助大脑（命令行版），--replay 文件 可离线回放
jcc autoroll --target 绯红树怪=3 --keep 10       # 自动 D 牌（加 --live 才真实操作）
jcc autopilot                    # 全自动托管（加 --live 才真实操作）
jcc calibrate board              # 标定棋盘四角（还有 buttons / bench）
jcc config set llm.model deepseek-chat         # 改设置
```

## 自动操作前必读

1. **默认是演练模式**：只在日志里记录要做的操作，不会点击。先用演练确认决策靠谱。
2. **先标定**：工具栏扳手菜单「坐标标定」，倒计时内把鼠标移到提示的位置（棋盘四角、备战席首尾、刷新/升级按钮）。
   棋盘格看不清时先拖起一个棋子让格子高亮。
3. 关闭演练后启动会再次确认。**急停**：工具栏「停止」、`⌘.`，或把鼠标甩到主屏左上角。
4. 若画面连续没有变化（点击没生效），全自动模式会自动暂停，检查标定或是否有窗口挡在游戏前面。

## 大模型（可选）

不开大模型也能用：规则引擎离线给出全部建议。开启后，大模型拿「结构化状态 + 规则建议 + 候选阵容 + 概率」做综合判断
（是否转阵容、保血还是吃利息、海克斯怎么选），每回合每阶段最多问一次，结果显示在「实时决策」页的「AI」一栏。

当前接入的是智谱 GLM-5.3 系列（OpenAI 兼容协议，`https://open.bigmodel.cn/api/paas/v4`）。GLM-5.3 始终开启深度思考，
按实测（真实对局状态、多次取中位数）做了三档预设，在工具栏 **AI** 弹出框里切换（`⌘⇧1/2/3`），状态栏显示当前档位：

| 档位 | 模型 | 平时思考 | 海克斯思考 | 实测耗时 |
|---|---|---|---|---|
| 极速 | glm-5.3-flashx | low | low | 约 2.5 秒，最稳定 |
| **均衡（推荐，默认）** | glm-5.3 | low | high | 平时约 4 秒，海克斯约 10 秒 |
| 深度 | glm-5.3 | high | high | 约 9 秒 |

测试过但没采用：`glm-5.3-flash`（low 约 4.8 秒，不比标准版快，偶有 30 秒长尾和截断输出）；
`max` 思考强度（超过 40 秒，海克斯选择只有约 30 秒）。思考也会占用输出 token，「最大输出 token」默认 3000。

```bash
jcc llm test                      # 测试连接
jcc llm ask                       # 对当前画面问一次（--replay 截图目录 可离线）
jcc llm preset fast               # 切换档位：fast / balanced / deep（不带参数列出全部）
jcc config set llm.reasoning_effort high
```

换别的模型：设置 → 大模型，协议选 `openai`（DeepSeek、通义、Kimi、本地 Ollama 等，base_url 填到 `/v1`）或 `anthropic`。
API Key 只保存在 `var/settings.json`（不入库），也可以用环境变量 `JCC_LLM_API_KEY`。

## 视觉模块

视觉在本进程内用纯 Python 完成（`src/jccbrain/vision/eye/`，由原 Swift 版 game-eye 移植，阈值与区域坐标沿用其实测值）：
Quartz 按窗口截图 → Apple Vision 中文 OCR（小区域放大、拼图批量识别）→ 血条定位单位、取色判星级与卡费 →
Vision 特征向量 + 图库认出英雄（买卡时自动学习，也可「工具 → 标注单位」手动标注）。单帧约 0.4~0.5 秒。

设置里可切换视觉来源：`pyeye`（实时画面，默认）或 `replay`（jsonl 状态文件或截图目录，离线调试）。
`jcc vision file 截图…` 可逐张输出识别结果。原 Swift 版 game-eye 及其 MCP 接口已弃用，只保留首次运行时导入它的单位图库；
视觉的待完善项见 `game-eye/待完善清单.md`。

## 已知限制

- 棋盘单位只有血条坐标，换算到格子依赖标定；默认值是按 1774×1136 窗口估的。
- 选秀、装备（身上/散件栏）、战利品法球还没有识别，全自动模式在这些环节不操作。
- 单个数字（如倒计时 0、人口「5/5」）偶尔漏读；后续可改为数字模板匹配（见 game-eye/待完善清单.md）。
- 看不到的对手持有张数无法计入卡池，概率偏乐观；可在「牌库概率」里手动填「别人拿走」。
- 规则表（卡池数量、经验表）按 S18 填写，版本调整时改 `src/jccbrain/data/rules/set18.json`；其他赛季还没有自己的规则表时沿用自然之力的（状态栏会提示）。
